# Security policy

This repository hosts a synthetic wireframe. Do not submit real candidate, employee, customer, authentication or provider data to the application, repository, issues or test artifacts.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository when available. Do not open a public issue containing exploit details, credentials or personal data. Include affected route/component, reproduction using fictional data, impact and suggested containment.

Supported security updates apply to the current `main` branch. The public GitHub Pages build has no backend, authentication, upload, persistence or external write capability. That boundary is not a claim that a future production system is secure; production requires the separate threat-model, authorization, identity, provider, operations and assurance gates in the PRD.
